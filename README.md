# Miteezy solar homepage

Responsive Next.js homepage for Miteezy International Services Limited, built for Vercel.

## Run locally

```sh
pnpm install
pnpm dev
```

Run `pnpm lint`, `pnpm typecheck`, and `pnpm build` before publishing changes.

## Deploy on Vercel

Import this GitHub repository in Vercel. Vercel detects Next.js automatically. Keep the root directory as `/` and use the default build settings. No environment variables are required. Once a domain is assigned, add its URL to `metadataBase` in `app/layout.tsx` and to the sitemap if you add one.
